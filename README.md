# II&M Next.js site

The Bootstrap HTML site in `medicinebootstrape/iim-bootstrap-frontend` is converted into this Next.js App Router project.

```bash
npm install
npm run dev
```

Open http://localhost:3000

- Shared chrome: `components/Header.js`, `components/Footer.js`
- Page styles: `app/globals.css` (imported once from the root layout)
- Images: `public/images`
- Routes match the original HTML pages: `/`, `/about`, `/education`, `/consultation`, `/speaking`, `/research`, `/resources`, `/books`, `/bioscience`, `/courses`, `/curriculum`, `/workshops`, `/podcast`, `/donate`, `/team`, `/mission`, `/impact`
